# Arquitectura Frontend
- Aplicación Web Vanilla (HTML5, CSS3, JavaScript ES Modules).
- Estructura modular:
  - `index.html`: Estructura principal y layout de la UI.
  - `css/estilos.css`: Estilos visuales.
  - `js/api.js`: Módulo de conexión con la API REST (fetch).
  - `js/state.js`: Módulo para la gestión del estado de la aplicación.
  - `js/app.js`: Módulo principal para el manejo del DOM y eventos
